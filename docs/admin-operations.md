# 客服后台本地操作手册

## 接单

1. 使用本地后台令牌进入 `/admin.html`。
2. 查看新需求和10分钟响应状态，点击“处理”完成认领。
3. 电话或企业微信确认材料、尺寸、数量、工艺和交期。
4. 创建确认报价；报价确认后，客户提出的材料、尺寸或描述变化只生成变更申请，不会覆盖原需求，原报价不能继续确认付款。

## 付款与生产

1. 核对正式报价与实际到账记录。
2. 仅在全额到账后执行“确认全额到账并建单”。
3. 按生产、质检、待交付、已完成顺序发布客户可见节点。
4. 公开说明不得填写成本、内部工艺备注、员工隐私或付款账号。

## 通知与异常

- 每个客户可见节点生成独立通知任务，重复提交同一节点不会重复发送。
- 通知服务未配置或发送失败时，任务保持失败状态并生成后台待办，不会标记为已发送。
- 本地版本不连接真实微信、短信或邮件；正式接入后再进行发送与重试演练。

## 安全边界

- 后台令牌模式仅供本机验收，不允许直接暴露到公网。
- 图纸和附件保存在非公开目录；不得复制到 `public/`。
- 阿里云上线前必须完成操作员账号、角色权限、HTTPS、病毒扫描、备份恢复和审计演练。
