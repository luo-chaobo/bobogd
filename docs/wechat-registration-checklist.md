# 微信小程序与企业微信资料清单

## 小程序基础资料

- 名称：未来机械钣金服务
- 简称：未来机械
- 介绍：面向设备制造与工程改造客户，提供非标钣金需求提交、图纸与照片上传、客服沟通及订单公开进度查询服务。
- 头像：`public/assets/brand/wl-mark-144.png`
- 服务类目：按微信后台当前可选类目，优先选择与机械制造、企业服务或工具服务相符的实际类目，不提交与实际业务不一致的类目。

## 小程序上线前

1. 完成企业主体认证和管理员绑定。
2. 在服务器域名中配置正式HTTPS API与文件上传域名。
3. 配置用户隐私保护指引，说明手机号、联系人、地区、加工资料和附件用途。
4. 申请并配置报价、到账、生产、质检、交付和延期相关订阅消息模板。
5. 将测试AppID、模拟登录和本地API地址替换为正式配置。
6. 使用体验成员完成有图、无图、登录、手机号绑定、订单权限和订阅消息真机测试。

## 企业微信

- 企业头像：`brand/wecom-avatar-1024.png`
- 企业名片横版标识：`brand/logo/wl-lockup-horizontal.svg`
