# 本地验收清单

## 企业官网

- 检查首页及加工能力、行业方案、案例、工厂、流程、下单、查询、资讯、关于、联系、隐私和服务规则页面。
- 桌面导航可进入订单查询、资讯中心和联系我们；手机底部可电话、查询和下单。
- 核对地址、电话、备案号、企业微信二维码及图片授权。地址当前必须保留“上线前核对”标识。

## 交易平台

- 打开 `/platform.html`，检查六类需求入口、工厂实景、宣传片、流程、案例、无图说明、付款规则、FAQ和需求表单。
- 验证25秒宣传片可播放、可拖动，手机网络下使用Byte Range分段加载。
- 页面底部客户中心必须使用订单号与手机号共同验证，不显示其他客户或内部信息。
- 本地页面通过后，仅记录 `order.wljixie.com` 映射方案；不在本阶段修改DNS。

## 接单闭环

- 分别提交有图纸和无图纸需求。
- 验证最多3个附件、单个20MB、总计30MB限制。
- 完成认领、报价、人工确认到账、生产、质检、待交付和完成节点。
- 使用订单号和手机号核对公开进度，确认不显示金额、内部备注和员工信息。

## 小程序

- 使用微信开发者工具导入 `miniprogram/`，开发阶段启用服务端两个 mock 开关。
- 验证登录、手机号绑定、草稿更新后提交、附件上传、我的需求、我的订单和订单详情。
- 正式 AppID、真实登录、手机号授权、订阅模板、企业微信客服链接和二维码均属于账号就绪后的联调项。

## 阶段边界

- 本清单完成只代表本地验收通过。
- 不执行阿里云部署、对象存储、备案接入、HTTPS、DNS或正式域名切换。
