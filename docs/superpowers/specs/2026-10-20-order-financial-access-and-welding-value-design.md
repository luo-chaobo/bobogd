# 订单财务权限与焊接产值统计设计

## 目标

在 BOBO 工单中增加订单单价和计算所得总金额，并将财务数据限制给罗朝波、郑金波、郑学良对应的员工账号。管理分析导出新增焊接产值工作表，同时保留报工明细和每位焊接工的产值汇总，供绩效核算参考。

## 订单金额与授权

- 新建订单表单在数量、交期下方并排显示“单价”和“总金额”。单价可选填；总金额只读，按单价乘订单数量计算。
- 订单编辑表单允许授权人员修改单价。数量或单价变化时总金额重新计算。订单只需保存单价；总金额由服务端计算，忽略或拒绝客户端传入的总金额。
- 金额按人民币、两位小数处理。单价为空时总金额为空，不显示为 0。
- 实施时按三个指定姓名定位现有员工账号。只有姓名恰好唯一匹配时才将权限绑定到对应账号 ID；缺失或重名时失败关闭并记录可诊断错误，不授权任何模糊匹配账号。
- 服务端增加独立财务查看/编辑授权。未授权账号的页面和所有 API 响应均不返回单价或总金额，包括订单对象、工单嵌套订单、配送响应及集成响应。未授权的写请求不得新增或修改单价。
- 管理报表导出保留现有管理权限要求；只有财务授权账号的导出文件包含“焊接统计”工作表，其他账号的文件不创建该工作表。

## 焊接统计口径

- 工作表位置在“人员分析”之后、“指标口径与来源”之前。
- 逐条明细仅纳入统计日期范围内的正常路线焊接生产报工；排除质检报工、返工路线，并沿用当前工作簿排除罗朝波操作记录的规则。
- 明细包含焊接工、订单/工单、产品、工序、报工时间、单位、计入完成数量、订单单价和本次产值。本次产值等于计入完成数量乘订单单价。
- 同一工作表上方增加按焊接工汇总的产值表，按员工汇总其明细金额，并列出未计价报工数。若员工存在未计价报工，已计价金额仍显示，但明确标注为部分统计，避免被当作完整绩效总额。
- 未填写单价的订单仍出现在报工明细中；其单价和产值为空。

## 接口与数据兼容

- 订单可新增可选 `unitPrice`；历史订单和外部平台订单没有该字段时保持为空，不要求批量回填或迁移。
- 权限响应提供财务查看权限标记，前端据此决定是否渲染金额字段；权限判断和字段过滤始终在服务端执行。
- 既有报表工作表、统计日期范围和图表保持不变。

## 验收

- 覆盖单价空值、合法金额、非法负数/格式、金额两位小数、数量变化重算，以及伪造 `totalAmount` 的请求。
- 覆盖三名授权账号与普通账号在创建、编辑、bootstrap、嵌套订单、配送/集成响应和管理报表中的可见性及写权限。
- 覆盖焊接逐条明细、正常路线过滤、返工/质检排除、未定价行、每位焊接工的合计与未计价条数、日期范围和罗朝波排除口径。
- 验证工作表顺序和原有工作表内容不回归；仅进行本地代码和测试验证，不包含线上部署或小程序发布。
