# 企业官网与独立交易平台设计规格

## 目标与定位

- `wljixie.com` 是完整企业官网，负责建立制造能力、工厂实力、案例、行业方案和服务可信度。
- `order.wljixie.com` 是转化型交易平台，负责激发询价意愿、收集加工需求和提供客户订单查询。
- 两者共享宁波未来机械品牌、真实工厂素材、接单 API 和订单状态 API，但页面信息结构与转化目标不同。

## 企业官网

首页从简单三卡片扩展为：品牌主张、可接需求、核心工艺、行业应用、精选案例、工厂与质检、服务优势、交付流程、知识内容和最终行动区。现有能力、方案、案例、工厂、流程、资讯等独立页面继续保留，并从首页提供明确入口。

官网所有“快速下单”链接在本地指向 `/platform.html`，正式部署到主域后指向 `https://order.wljixie.com/`。企业官网不放置长表单，避免展示与交易任务混在一起。

## 交易平台

交易平台采用用户认可的深蓝、橙色工业视觉，并建设为完整长页面：

1. 首屏承诺：急件、小批量、无图可沟通、工作时段10分钟响应。
2. 高频需求入口：有图纸、无图纸、维修替换、小批量打样、设备罩壳、机架机箱。
3. 真实媒体：现有工厂、激光、折弯、焊接、表面处理、成品图片。
4. 20–30秒静音宣传片：只使用已有真实照片、文字和品牌色，不生成虚构设备或产能。
5. 工艺与案例证据：问题、处理方式和交付关注点，不编造客户名、精度、设备数量和认证。
6. 六步服务闭环与付款后开工说明。
7. 无图下单指南、常见问题和重复行动按钮。
8. 完整下单表单，继续调用 `/api/inquiries`。
9. 页面底部“客户订单中心”，使用订单号和手机号调用 `/api/order-status`。
10. 页脚保留客户入口、隐私政策、服务规则、工作时间、备案信息和地址核对提示。

## 视觉与交互

- 主色：深蓝黑 `#0e1a24`，强调色 `#f36b2d`，浅底 `#f4f5f4`，正文保持 WCAG AA 对比度。
- 页面最大宽度约1200px，使用8px间距体系；正文最小16px，按钮触控高度不低于46px。
- 图片明确宽高或比例，首屏图片优先加载，其他图片与视频延迟加载。
- 每个主要内容段只保留一个橙色主行动，辅助链接使用描边或文字样式。
- 移动端固定保留电话、订单查询、提交需求三个入口，并为固定栏预留页面底部空间。
- 动效只使用轻微淡入、按钮反馈与媒体播放状态，支持 `prefers-reduced-motion`。

## 子域名与本地映射

- 正式推荐子域名：`order.wljixie.com`。
- 本地验收地址：`http://127.0.0.1:8090/platform.html`。
- 部署时由反向代理把 `order.wljixie.com/` 映射到同一应用的 `/platform.html`，API继续使用同源 `/api/*`，避免跨域和重复认证配置。

## 验收边界

- 本阶段生成本地页面、真实照片宣传片、内容结构、客户入口和测试，不执行阿里云、DNS或正式子域名配置。
- 视频是现有真实照片组成的宣传片，不表示连续现场拍摄；以后可无结构变更地替换为真实工厂视频。
- 客户后台一期指订单查询中心，不建设网页用户名密码账户；微信客户中心继续由小程序承载。
