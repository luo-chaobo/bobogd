# 数据分析访问契约

## 一期：ECS 本地 SQLite 与脱敏汇总

- ECS 本地 SQLite 仅允许应用访问；分析人员不直接访问数据库文件。
- 允许输出：按批准口径生成的汇总 CSV/XLSX，必须注明生成时间和 schema version。
- 必须删除或掩码：手机号、联系人身份、附件 URL、图纸元数据、付款凭据、内部成本和内部备注。
- 初始指标：需求数、首次响应时长、超时率、报价数、报价转订单率、交付周期、订单状态分布、来源渠道、通知失败数。
- 禁止输出：SQLite 数据库及 `-wal`/`-shm`、原始附件、凭据、完整审计日志。

生产数据是业务事实主档；Git 和 Obsidian只接收批准后的脱敏汇总，不接收数据库副本或客户原始资料。

## 二期：RDS MySQL 与 DMS

迁移至 RDS MySQL 后，协作者使用独立 RAM 身份，并通过 DMS 获得最小权限、可审计的数据访问。身份、查询范围和导出权限均应独立控制；未经批准不得共享凭据或直接导出明细。
