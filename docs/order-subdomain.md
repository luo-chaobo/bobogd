# `order.wljixie.com` 上线映射说明

## 域名职责

- `wljixie.com`：企业官网、能力、案例、工厂与资讯内容。
- `order.wljixie.com`：快速下单、资料上传、服务说明和页面底部客户订单查询。
- 本地验收继续使用 `/platform.html`；生产环境把子域名根路径映射到该页面，不复制业务代码。

## 生产反向代理要求

以下为后续阿里云部署约束，本阶段不执行：

1. `order.wljixie.com/` 内部映射到应用的 `/platform.html`。
2. `/styles.css`、`/app.js`、`/assets/*` 和 `/api/*` 转发到同一应用，保证表单、附件和订单查询同源。
3. 保留客户端请求的 `Range` 头，不缓存或压缩MP4字节范围响应；透传 `206`、`Content-Range` 和 `Accept-Ranges`。
4. 仅开放公开接口；`/admin.html` 与 `/api/admin/*` 应限制到企业网络、VPN或独立管理域名。
5. HTTP永久跳转HTTPS，证书同时覆盖 `wljixie.com` 和 `order.wljixie.com`，或分别签发证书。

## 阿里云与微信检查项

- 在阿里云DNS新增 `order` 记录，切换前先降低TTL并保留回退记录。
- 确认备案接入覆盖该子域名，页脚展示已核准的备案信息。
- 在微信公众平台配置HTTPS request、uploadFile、downloadFile合法域名及业务域名。
- 检查对象存储私有权限、临时访问地址、数据库备份、上传扫描、日志和告警。
- 实测官网到交易平台跳转、需求提交、附件上传、订单查询、视频播放及手机端固定入口。

## 回退方式

切换前保留旧站备份和原解析值。若交易平台发生阻断性故障，将 `order` 解析恢复到原值或临时维护页；官网和波波工单保持独立，不随交易平台一起回退。
